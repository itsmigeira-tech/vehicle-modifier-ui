# Vehicle Modifier UI

A sleek, compact, and minimizable Roblox vehicle modifier script featuring glossy glassmorphic UI controls.

## Features
- **Enabled:** Toggle vehicle modification on/off
- **Acceleration:** Custom acceleration force modifier
- **Deceleration:** Custom braking/deceleration multiplier
- **Minimizable UI:** Compact toggleable frame with smooth animations

## Quick Loadstring
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/itsmigeira-tech/vehicle-modifier-ui/main/Main.lua"))()
```
